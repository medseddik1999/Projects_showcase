# Abdelhakim Seddik — Portfolio professionnel

Nouvelle version du portfolio, inspirée de la référence sombre et ambrée fournie. Le portrait a été créé à partir des photos personnelles ; les trois captures de projets sont les fichiers fournis, conservés sans modification.

## Le site

- Présentation de Data Scientist / Data Analyst.
- Portrait professionnel, biographie et informations de profil.
- Compétences regroupées en savoir-faire, savoir-être et outils.
- Quatre projets détaillés, en grille fixe : API NLP, Poland Biodiversity, Rent Dashboard et Trading Bot Backtesting.
- Visuels agrandissables, outils utilisés et accès au code de chaque projet.
- Accès au profil GitHub pour les autres projets.
- Parcours, formation, certifications, coordonnées et CV téléchargeable.
- Menu mobile, navigation au clavier et respect des préférences de réduction des animations.

Cette version est séparée de l’ancienne version cartoon.

## Ouvrir le portfolio

Décompressez l’archive et ouvrez `dist/index.html` dans un navigateur. Le site est statique et ne demande aucune compilation.

Le portrait, les captures, l’illustration NLP, le CV, les styles et le JavaScript sont inclus dans l’archive. Les polices Google Fonts et certains logos Simple Icons nécessitent une connexion internet. Des polices système sont prévues en remplacement.

## Publier avec GitHub et Netlify

Déposez le contenu de cette archive dans votre dépôt GitHub : `netlify.toml` doit se trouver à la racine, à côté du dossier `dist`.

Pour Netlify :

- Dossier à publier : `dist`.
- Commande de compilation : aucune.
- La configuration est déjà fournie dans `netlify.toml`.

Si vous utilisez un dépôt manuel, envoyez directement le dossier `dist`.

Le site n’a pas été publié automatiquement.

## Modifier le contenu

- Textes, coordonnées, projets et liens : `dist/index.html`.
- Couleurs, typographie et adaptation aux écrans : `dist/styles.css`.
- Menu, navigation active et apparitions : `dist/script.js`.
- CV : `dist/assets/CV_Abdelhakim_SEDDIK.pdf`.
- Portrait : `dist/assets/portrait-pro.png`.
- Visuels de projets : `dist/assets/projects/`.

## Sélection et vérifications

La sélection couvre quatre compétences complémentaires : mise à disposition d’un modèle NLP par API, exploration géographique, analyse métier et simulation quantitative. Les quatre dépôts sont publics, non archivés et ne sont pas des forks au moment de la vérification. Les technologies affichées sont issues des fichiers des dépôts et de leur documentation.

Les informations de parcours, de formation et de certification proviennent du CV fourni. Aucun résultat chiffré, taux de compétence ou témoignage client n’a été inventé.

La structure HTML, les références locales, les liens internes et la syntaxe JavaScript ont été contrôlés. L’archive a été vérifiée. Le rendu visuel dans un navigateur et la disponibilité des ressources externes n’ont pas pu être testés dans cet environnement.

Voir `SOURCES.md` pour les sources des projets et `VISUELS.md` pour les fichiers et les prompts des images générées.
